## **1️⃣ Configuración de Eureka Server**
📌 **Configuración de `application.yml`**
```yaml
server:
  port: 8761

eureka:
  instance:
    hostname: localhost
  client:
    register-with-eureka: false
    fetch-registry: false
```
📌 **Habilitamos Eureka Server (`EurekaServerApplication.java`)**
```java
package com.ejemplo.eureka;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.netflix.eureka.server.EnableEurekaServer;

@SpringBootApplication
@EnableEurekaServer
public class EurekaServerApplication {
    public static void main(String[] args) {
        SpringApplication.run(EurekaServerApplication.class, args);
    }
}
```

## **2️⃣ API Gateway con Spring Cloud Gateway**
📌 **Configuramos `application.yml`**
```yaml
server:
  port: 8080

spring:
  application:
    name: api-gateway

eureka:
  client:
    service-url:
      defaultZone: http://localhost:8761/eureka/

routes:
  - id: pedidos
    uri: lb://pedidos-service
    predicates:
      - Path=/pedidos/**
  - id: pagos
    uri: lb://pagos-service
    predicates:
      - Path=/pagos/**
  - id: notificaciones
    uri: lb://notificaciones-service
    predicates:
      - Path=/notificaciones/**
```
📌 **Habilitar API Gateway (`ApiGatewayApplication.java`)**
```java
package com.ejemplo.gateway;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.netflix.eureka.EnableEurekaClient;

@SpringBootApplication
@EnableEurekaClient
public class ApiGatewayApplication {
    public static void main(String[] args) {
        SpringApplication.run(ApiGatewayApplication.class, args);
    }
}
```

# **3️⃣ Despliegue en Kubernetes con Helm y Terraform**
📌 **Creamos Helm Chart para la aplicación**
```sh
helm create mi-app-chart
```
📌 **Archivo `values.yaml`**
```yaml
replicaCount: 3
image:
  repository: mi-aplicacion
  tag: "v1"
service:
  type: LoadBalancer
  port: 80
```
📌 **Instalamos la aplicación en Kubernetes con Helm**
```sh
helm install mi-aplicacion ./mi-app-chart
```

📌 **Terraform para aprovisionar recursos en la nube**
```hcl
resource "kubernetes_deployment" "app" {
  metadata {
    name = "mi-aplicacion"
    labels = {
      app = "mi-app"
    }
  }
  spec {
    replicas = 3
    selector {
      match_labels = {
        app = "mi-app"
      }
    }
    template {
      metadata {
        labels = {
          app = "mi-app"
        }
      }
      spec {
        container {
          image = "mi-aplicacion:v1"
          name  = "mi-app"
          port {
            container_port = 8080
          }
        }
      }
    }
  }
}
```
📌 **Aplicamos Terraform**
```sh
terraform init
terraform apply
```

✅ **La infraestructura ahora está en la nube.**

# **4️⃣ Configuración de CI/CD con GitHub Actions y ArgoCD**
📌 **Archivo `.github/workflows/deploy.yml`**
```yaml
name: Deploy to Kubernetes

on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repo
        uses: actions/checkout@v2

      - name: Build Docker Image
        run: |
          docker build -t mi-aplicacion:v1 .
          docker tag mi-aplicacion:v1 myregistry.com/mi-aplicacion:v1
          docker push myregistry.com/mi-aplicacion:v1

      - name: Deploy to Kubernetes
        run: |
          kubectl apply -f k8s/deployment.yaml
          kubectl apply -f k8s/service.yaml
```
📌 **Aplicamos despliegue con ArgoCD**
```sh
argocd app create mi-aplicacion --repo https://github.com/user/repo.git --path k8s --dest-server https://kubernetes.default.svc --dest-namespace default
```
✅ **Ahora cada push a `main` despliega automáticamente la aplicación.**

# **5️⃣ Monitorización con Prometheus y Grafana**
📌 **Configuramos `prometheus.yaml`**
```yaml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'mi-aplicacion'
    static_configs:
      - targets: ['mi-aplicacion:8080']
```
📌 **Desplegamos Prometheus y Grafana**
```sh
kubectl apply -f prometheus-deployment.yaml
kubectl apply -f grafana-deployment.yaml
```
📌 **Accedemos a Grafana en `http://localhost:3000` y configuramos Prometheus.**

✅ **¡Ahora tenemos métricas en tiempo real!**
