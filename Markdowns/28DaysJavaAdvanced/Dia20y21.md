## **1️⃣ Eureka Server (Service Discovery)**
📌 **Configuración de `application.yml`**
```yaml
server:
  port: 8761

eureka:
  instance:
    hostname: localhost
  client:
    register-with-eureka: false
    fetch-registry: false
```
📌 **Habilitar Eureka Server (`EurekaServerApplication.java`)**
```java
package com.ejemplo.eureka;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.netflix.eureka.server.EnableEurekaServer;

@SpringBootApplication
@EnableEurekaServer
public class EurekaServerApplication {
    public static void main(String[] args) {
        SpringApplication.run(EurekaServerApplication.class, args);
    }
}
```
✅ **Ejecutamos Eureka y verificamos en:**  
📍 **http://localhost:8761/**

## **2️⃣ API Gateway (Zuul o Spring Cloud Gateway)**
📌 **Configuración de `application.yml`**
```yaml
server:
  port: 8080

spring:
  application:
    name: api-gateway

eureka:
  client:
    service-url:
      defaultZone: http://localhost:8761/eureka/

routes:
  - id: pedidos
    uri: lb://pedidos-service
    predicates:
      - Path=/pedidos/**
  - id: pagos
    uri: lb://pagos-service
    predicates:
      - Path=/pagos/**
  - id: notificaciones
    uri: lb://notificaciones-service
    predicates:
      - Path=/notificaciones/**
```
📌 **Habilitar API Gateway (`ApiGatewayApplication.java`)**
```java
package com.ejemplo.gateway;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.cloud.netflix.eureka.EnableEurekaClient;

@SpringBootApplication
@EnableEurekaClient
public class ApiGatewayApplication {
    public static void main(String[] args) {
        SpringApplication.run(ApiGatewayApplication.class, args);
    }
}
```
✅ **Ahora todas las solicitudes pasan por `http://localhost:8080/`**

## **3️⃣ Auth Service (Spring Security + OAuth2 + JWT)**
📌 **Dependencias (`pom.xml`)**
```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-oauth2-resource-server</artifactId>
</dependency>
```
📌 **Configuración de seguridad (`SecurityConfig.java`)**
```java
package com.ejemplo.auth.security;

import org.springframework.context.annotation.Bean;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.web.SecurityFilterChain;
import static org.springframework.security.config.http.SessionCreationPolicy.STATELESS;

public class SecurityConfig {
    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/auth/**").permitAll()
                .anyRequest().authenticated()
            )
            .oauth2ResourceServer(oauth2 -> oauth2.jwt());
        return http.build();
    }
}
```
✅ **Protegemos todos los endpoints excepto `/auth/**`.**

## **4️⃣ Pedidos Service**
📌 **Modelo `Pedido.java`**
```java
@Entity
public class Pedido {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String producto;
    private int cantidad;
    private BigDecimal total;
}
```
📌 **Feign Client para llamar a Pagos Service**
```java
@FeignClient(name = "pagos-service")
public interface PagosClient {
    @PostMapping("/pagos/procesar")
    String procesarPago(@RequestParam Long pedidoId, @RequestParam BigDecimal monto);
}
```
✅ **Cada vez que se crea un pedido, se llama a `PagosClient`.**

---

## **5️⃣ Pagos Service (Kafka)**
📌 **Configurar Kafka en `application.yml`**
```yaml
spring:
  kafka:
    bootstrap-servers: localhost:9092
    producer:
      key-serializer: org.apache.kafka.common.serialization.StringSerializer
      value-serializer: org.apache.kafka.common.serialization.StringSerializer
```
📌 **Productor de Kafka (`KafkaProducer.java`)**
```java
@Service
public class KafkaProducer {
    private final KafkaTemplate<String, String> kafkaTemplate;

    public void enviarMensaje(String mensaje) {
        kafkaTemplate.send("pagos", mensaje);
    }
}
```
✅ **Cada pago genera un evento en Kafka.**

---

## **6️⃣ Notificaciones Service (Consumidor de Kafka)**
📌 **Consumidor de Kafka (`KafkaConsumer.java`)**
```java
@KafkaListener(topics = "pagos", groupId = "notificaciones")
public void recibirMensaje(String mensaje) {
    System.out.println("Notificación enviada: " + mensaje);
}
```
✅ **Cada pago es procesado y notificado en tiempo real.**
